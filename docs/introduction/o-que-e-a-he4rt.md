# O que é a He4rt

A He4rt Developers é uma comunidade brasileira de pessoas desenvolvedoras que
se reúne para aprender, ensinar e construir projetos em conjunto. Este portal
documenta como a plataforma funciona, das decisões de arquitetura ao dia a dia
de cada módulo.
