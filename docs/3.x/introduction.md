# Introdução ao He4rt Bot API

Bem-vindo à documentação oficial do **He4rt Bot API**!

## O que é o He4rt Bot?

O He4rt Bot é uma API desenvolvida em Laravel para gerenciar interações, gamificação e funcionalidades da comunidade He4rt Developers.

## Principais Funcionalidades

- 🎮 **Gamificação**: Sistema de badges, rankings e temporadas
- 💬 **Mensagens**: Gerenciamento de mensagens da comunidade
- 👥 **Usuários**: Sistema completo de gestão de membros
- 🎯 **Feedback**: Coleta e análise de feedbacks
- 🔗 **Integrações**: Conexões com plataformas externas

## Tecnologias Utilizadas

- Laravel 12.x
- PHP 8.3+
- PostgreSQL
- Redis
- Livewire/Flux

3. Execute as migrações
4. Inicie o servidor
