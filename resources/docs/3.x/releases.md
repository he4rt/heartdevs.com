## Versioning Scheme

O projeto segue [versionamento semântico](https://semver.org/lang/pt-BR/) por
linha de release (`MAJOR.MINOR.PATCH`):

- **MAJOR** — mudanças incompatíveis, que exigem ajustes ao atualizar.
- **MINOR** — funcionalidades novas retrocompatíveis.
- **PATCH** — correções de bug retrocompatíveis.

A documentação acompanha a linha **MAJOR.x** (por exemplo, `3.x`). Os links entre
páginas usam o placeholder `{{version}}` para resolver sempre a versão corrente.

<a name="support-policy"></a>

## Support Policy

A linha de release atual recebe correções de bug e melhorias de forma contínua.
Releases são marcadas via tags no repositório `he4rt/he4rt-bot-api`; as mudanças
de cada uma podem ser acompanhadas pelas releases do GitHub e pelas issues
associadas.

Para começar a contribuir, veja
[Seu Primeiro Pull Request](/docs/{{version}}/primeiro-pull-request).
